# Manual do usuário — Sistema de Gestão de Locações Dimaq

`manual.html` é a fonte do manual; as telas ficam em `img/`. Para gerar o PDF, abra o HTML
num navegador e use **Imprimir → Salvar como PDF** (A4, com gráficos de fundo ativados).

As capturas foram feitas num ambiente de teste com dados fictícios.
